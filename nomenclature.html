Step-by-Step Nomenclature Guide

To put a name together, you must identify these four parts:

Substituents Parent Chain Unsaturation Principal Functional Group
Use prefix Use prefix/root Use suffix Use suffix

Remember from class:

Substituents = Any group coming off of parent chain, may include:

  • Any functional group that is not the highest priority functional group on the molecule
  • Carbon-based groups (straight chain or specific patterns of carbon groups)
  • Halogens

Parent Chain = Longest continuous carbon chain that contains the most principal functional groups

  • If no functional groups are present or doing this results in a tie, then the longest continuous carbon chain that contains the most double bonds
  • If still resulting in tie, then longest continuous carbon chain that also contains the most triple bonds

Unsaturation = Presence of any double or triple bonds (or lack thereof)

Principal Functional Group = Highest priority functional group (refer to table provided in class for order)

To then actually name the molecule:

  1. Identify principal functional group
    1. Identify functional group and determine which one has the highest priority.
      1. Choose appropriate suffix for this functional group and number based on Step 3 once that has been completed
  2. Identify parent carbon chain
    1. Find the longest continuous carbon chain that contains the most “principal functional groups” if any were identified
    2. If no functional groups are present or 2a results in a tie, choose the chain that contains the most principal functional groups and the most double bonds.
    3. If no functional groups are present and no double bonds are present or 2b. results in a tie, choose the chain that contains the most principal functional groups, the most double bonds, and the most triple bonds.
  3. Number the parent carbon chain that gives the lowest possible number to the highest priority item
    1. Principal functional group
    2. Double bond
    3. Triple bond
  4. Identify unsaturation status
    1. Are there double and/or triple bonds?
      1. If yes, locate them and use the lowest number carbon the bond is involved with to number it
    2. Use a counting prefix modifier (di, tri, tetra, etc.) to indicate how many there are if more than 1 exists
    3. If there are no double or triple bonds present, we will use the alkane suffix, “-ane”.
  5. Locate substituents
    1. Everything else that has yet to be taken into account is now considered a substituent of the parent chain.
      1. Number them all based on the numbering done from Step 3
      2. If you have any substituents that are identical to each other, group them together and place the appropriate counting prefix modifier in front of it. Numbers associated with all of these substituents will be placed in front of the counting prefix.
  6. Put all substituents in alphabetical order
    1. “Iso-”, “cyclo-”, and “neo-” groups are counting in alphabetizing
      1. Note, in this class, we only have seen “iso-” and “cyclo-”
    2. “tert-”, “sec-”, “n-” prefixes are not counted in alphabetizing
      1. Note, in this class, we have only seen “tert-”
    3. Counting prefix modifiers are also not counted in alphabetizing
  7. Combine the pieces
    1. Use commas between numbers
    2. Use hyphens anytime you change from numbers to letters
    3. If the letter that comes after your parent chain is a vowel, drop the “a” at the end of the parent chain prefix/root
    4. If any unsaturation suffix is not the last suffix in the name, drop the “e” and the end of the suffix
